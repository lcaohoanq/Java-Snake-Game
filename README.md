# 🐍 Java Snake Game

![Animation](https://github.com/lcaohoanq/Java-Snake-Game/assets/136492579/1c4782eb-ccf4-437e-a6b1-900ec68a58a3)

A simple and fun Snake Game built with **Java Swing**, designed for learning and nostalgia.

## 🎮 Features
- Classic Snake gameplay with smooth controls
- On/off eating sound effect
- Increasing difficulty as the snake grows
- Game Over detection and scoring system
- Minimalist UI with responsive design

## 🧑‍💻 Technologies
- Java 17+
- Java Swing (GUI)
- Maven (build system)

## 🚀 Run Locally

### 1. Clone the project
```bash
git clone https://github.com/lcaohoanq/Java-Snake-Game.git
cd Java-Snake-Game
```

2. Build the project

```bash
mvn clean package -DskipTests=true -PmyProfile
```

3. Run the game
```bash
java -jar target/Snake-Game.jar
```
✅ Make sure Java 17+ is installed.
